DENTYAR V26 — بسته تغییرات آزمایشی

این بسته بر پایه V24 ساخته شده و شامل:
• فارسی‌سازی سراسری اعداد نمایشی
• نمایش تاریخ‌های خروجی برنامه به شمسی با ارقام فارسی
• پالت رنگ جدید و فاخر پزشکی/دندان‌پزشکی
• حفظ قابلیت بروزرسانی و ارسال برنامه

نکته مهم:
این فایل ZIP «منبع بروزرسانی» است، نه APK قابل نصب. مدیر بروزرسانی داخل نسخه اندروید باید APK جدید را دریافت و به Package Installer اندروید تحویل دهد. برای تست واقعی روی APK نصب‌شده، V26 باید با Capacitor/Android build و همان applicationId=ir.dentyar.app و کلید امضای نسخه قبلی ساخته شود.
