# DENTYAR V27 — استانداردسازی عملکرد و خروجی‌ها

این نسخه بر پایه V26 ساخته شده و تمرکز اصلی آن بر اصلاح عملکردهای واقعی برنامه است، نه فقط پیام موفقیت ظاهری.

## اصلاحات اصلی
- محاسبات مالی بازطراحی شد: مبلغ ناخالص، تخفیف، سهم بیمه، خالص، مجموع دریافتی، استرداد، پرداختی، مانده و بستانکاری/مازاد پرداخت از هم تفکیک شده‌اند.
- خدمات انتخاب‌شده در هر ویزیت علاوه بر عنوان ترکیبی، به‌صورت `serviceItems` نیز ذخیره می‌شوند.
- خروجی Excel و CSV اکنون نتیجه عملیات ذخیره/اشتراک را منتظر می‌ماند و پیام موفقیت قبل از انجام واقعی عملیات نمایش داده نمی‌شود.
- در نسخه Android/Capacitor، فایل گزارش در Documents/DENTYAR ذخیره و در صورت پشتیبانی، پنجره Share واقعی دستگاه باز می‌شود.
- در PWA/مرورگر، Web Share برای فایل و سپس دانلود استاندارد به‌عنوان مسیر جایگزین استفاده می‌شود.
- پشتیبان‌گیری نیز پیام موفقیت کاذب ندارد.
- «ارسال برنامه» به‌صورت فایل انتقالی HTML همراه/بدون اطلاعات انجام می‌شود و از Share واقعی دستگاه استفاده می‌کند؛ این فایل با APK اشتباه گرفته نمی‌شود.
- نسخه برنامه به V27 ارتقا یافت.
- نام فایل‌های پشتیبان و گزارش‌ها تاریخ شمسی دارند.

## نکته مهم درباره APK
خود برنامه نمی‌تواند APK نصب‌شده را از داخل خودش به یک پیام‌رسان تبدیل کند. برای ارسال «خود APK»، باید فایل APK ساخته‌شده در GitHub Actions/فرآیند Build را از بیرون برنامه به اشتراک گذاشت. گزینه انتقال داخل DENTYAR برای انتقال داده و نسخه HTML مستقل طراحی شده است.
