# DENTYAR V30

**DENTYAR — Your Smart Dental Assistant**

نسخه V30 بر پایه V29 اصلاح‌شده ساخته شده و اطلاعات محلی، LocalStorage و IndexedDB را حذف یا بازنشانی نمی‌کند.

## اصلاحات اصلی
- بازطراحی داشبورد دندان‌پزشکی با تم فیروزه‌ای تیره و کارت‌های کوچک و منظم
- حذف عبارات خراب مانند «سطوح» و «ستاره وجه»
- خلاصه مالی واحد؛ «مبلغ ناخالص خدمات»، «سهم بیمه» و «استرداد وجه»
- خدمات پرتکرار متصل به درمان‌های واقعی ثبت‌شده
- اعداد نمایشی فارسی، شامل شماره تماس و مبالغ
- هدر و لوگوهای قرینه و واکنش‌گرا
- نوار فیروزه‌ای زیر هدر و نوار امن پایین صفحه با Safe Area
- کش PWA و Manifest به V30
- ساختار تمیز GitHub با Workflow صحیح برای ساخت APK
- سازوکار بروزرسانی وب و APK بدون پاک‌کردن داده‌های بیمار

> برای GitHub، محتویات این بسته را در ریشه مخزن قرار دهید؛ پوشه `www` در زمان Build توسط Workflow ساخته می‌شود.
